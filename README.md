# Bhaavan Nimmagadda · Portfolios

Each portfolio lives in its own folder with its own files. Nothing is shared between folders, so changing one never affects another.

| Folder | What it is | Live link |
|---|---|---|
| `consulting/` | Consulting-style portfolio: executive summary, engagement case studies, track record, AI-built systems, leadership and education. | `/portfolio/consulting/` |
| `shipfolio/` | One-page portfolio built in Shipfolio, with React Bits text animations and Skiper UI / daisyUI components. | `/portfolio/shipfolio/` |

Each folder holds an `index.html` (the whole page) and an `assets/` folder for its own photos, logos and files. Plain HTML and CSS, no build step: open a folder's `index.html` locally, or view it on GitHub Pages.

The root `index.html` only redirects to `consulting/` so the old live link keeps working.

To add another portfolio, create a new folder with its own `index.html` and `assets/`, and add a row to the table above.
